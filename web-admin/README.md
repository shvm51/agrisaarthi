# AgriSaarthi Web Admin (experts + admins only)

Separate responsive web dashboard. Farmer experience stays mobile-first and is NOT duplicated here.

Planned navigation: Overview, Disease Hotspots, Farmers, Disease Cases, Experts, Weather Alerts, Markets, Reports, Knowledge Base.

Flagship: **Regional Disease Hotspot Map** — High/Medium/Low zones; click a zone → crop, disease, reported cases, risk trend, weather context, recommended surveillance.

Stack suggestion: Next.js + Tailwind + MapLibre, reading the same Supabase/PostGIS backend with role-based access (expert: assigned cases; admin: aggregates).

Status: scaffold placeholder for SIH — mobile + API are the primary deliverables.
